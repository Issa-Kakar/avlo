# @avlo/worker-shared

Server-only shared primitives for Cloudflare Workers. Uses ambient types (`R2Bucket`, `HTMLRewriter`, `caches.default`, `crypto.subtle`). **Never import from any client-side bundle.**

The package publishes TS source directly via `exports` (no dist build). Consumers (`workers/*`) resolve via the `@avlo/worker-shared` workspace dep + path mapping in their `tsconfig.json`. Client `tsconfig.json` and `tsconfig.sw.json` deliberately omit this path — accidental imports fail at typecheck.

## Files

| File | Exports |
|---|---|
| `src/index.ts` | Barrel re-export (only entry — no subpath exports declared) |
| `src/cors.ts` | `createCors({ methods, allowHeaders?, exposeHeaders? })` — per-worker Hono CORS factory; each worker advertises only the verbs + headers it serves (`OPTIONS` auto-appended). `isAllowedOrigin(origin, isDev)` + `isDevHost(host)` — the shared origin allow-list (prod `avlo.io`/`www.avlo.io`; `localhost:*` only when the request `Host` is dev), reused by the `hono/csrf` guard so origin policy is single-sourced. |
| `src/csp.ts` | `cspHeaders(profile)` — egress middleware stamping the profile on every returned response (H5; register early/route-scoped). `cspError(profile)` — `app.onError` companion that stamps thrown responses (csrf's 403) + unexpected 500s while preserving Hono's error log. `applyCsp(headers, profile)` — the underlying per-`Headers` factory (used by both + hand-built `Headers`). `CspProfile` (`'asset-body'` | `'api-json'`). **SPA HTTP headers are not set by a worker** — they live in `web/public/_headers`; the `avlo` site worker is assets-only (no worker script), so the Static Assets layer serves the SPA + those headers directly. |
| `src/ssrf.ts` | `isPrivateHost(hostname)` — blocks `localhost`/`*.localhost`, `.local`, `.internal`, trailing-dot variants (`localhost.`), IPv4 private/special ranges (127/8, 10/8, 172.16/12, 192.168/16, 169.254/16, 0/8, 100.64/10 CGNAT, 192.0.0/24, 198.18/15, ≥224 multicast+reserved), and IPv6 (`[::]`, `[::1]`, ULA fc00::/7, link-local fe80::/10, IPv4-mapped `::ffff:*` re-checked as v4). Used in Zod `.refine` AND re-run per redirect hop by `fetchGuarded`. |
| `src/cache-keys.ts` | `syntheticCacheUrl(service, key)` — namespaces synthetic edge-cache keys by service. `caches.default` keys on full URL; real URLs include host but synthetic keys are bare and easy to collide cross-service. |
| `src/fetch-bytes.ts` | `sha256Hex(data)` (content-addressing primitive, H4) + `fetchGuarded(url, opts?)` — SSRF-guarded fetch: http/https-only + `isPrivateHost` refusal + optional `hostAllowed` allowlist checked on the FIRST hop and EVERY redirect hop (`redirect: 'manual'` follow loop, ≤5 hops, ONE `AbortSignal.timeout` spanning the chain); returns the final `Response` or `null` on a refused hop / hop overflow + `fetchBytesCapped(url, maxBytes, opts?)` — ONE bounded fetch over `fetchGuarded` (the byte cap cancels the reader mid-stream). **Silent by design** (H10) — call sites own their redacted/grandfathered diagnostics. Returns `null` on non-OK/oversize/refused; network errors throw. Consumers: unfurl (page + og-image + favicon), avatar ingest (`hostAllowed: isAllowedAvatarHost`). |
| `src/dev-logs.ts` | Dev-only logging, gated by the orchestrator-injected `DEV_LOGS` binding (absent from every `wrangler.jsonc` ⇒ dormant in prod, nothing to strip). `isDevLogs(env)` — the one cast that reads it. `devRequestLogger()` — dev-gated `hono/logger` middleware (register after `createCors`, H6; H10-safe in prod since it's off). `devDrizzleLogger(env, label?)` — dev-gated Drizzle `logger` (SQL + params; structurally typed so this package needn't depend on drizzle-orm). `traceRpc(env, method, fn, outcome?)` — wrap an RPC impl to log `method → outcome · ms` (dev-gated; rethrows unchanged so the meta-RPC `forbidden`/`invalid-title` wire contract is intact). The queue projection heartbeat in `users/src/queue.ts` is the one **always-on** logger (H10-safe — counts + timing only). |
| `src/retry.ts` | `retryTransient(fn, maxAttempts=3)` — full-jitter backoff (100 ms base / 800 ms cap, mirrors `@avlo/db.withRetry`'s curve) retrying ANY error; **idempotent-ops-only** (KV put/delete, R2 put, GET fetch). Deliberately separate from `withRetry` (D1-specific transient regex; `@avlo/db` must not leak outside users). Never wrap a non-idempotent call — the OAuth token exchange is the canonical counter-example. |
| `src/surface-drift.ts` | `assertSurfaceMatch<Real, Mock>(true)` — Hono route-surface drift guard for the `app-type.ts` pattern (see `workers/CLAUDE.md` → App-Type Pattern). (Binary-RPC drift no longer has a guard here — it lives in native `implements <Surface>` clauses on the entrypoint classes; see `rpc-surfaces.ts`.) |
| `src/cookies.ts` | `verifyAnonToken` (raw HMAC verify + `AnonToken` parse — the RPC path, no Hono ctx), `mintAnonToken`, `cookieOpts` (dev/prod cookie attrs; prod `Domain=.avlo.io` + `SameSite=Lax` — also the `avlo_session` attrs), `parseCookieHeader` (raw `Cookie:`-header value extractor for no-ctx paths — auth's `readSession` is the second consumer), `ANON_COOKIE`, `AuthCtx`. Schema lives in `zod/anon-token.ts`. |
| `src/require-auth.ts` | `requireAuth<E>()` — generic Hono gate; verifies the session via the `AUTH` service RPC into `c.get('userId')` (401 if absent). The generic constraint pins `AUTH` to `AuthRpcSurface` (each caller's env types it via `RefineBindings`), so the gate calls `c.env.AUTH.verifySession` with no cast. Called with an explicit env arg per worker. |
| `src/rate-limit.ts` | `userRateLimiter<E>(binding)` — tier-1 `cloudflareRateLimiter` keyed on `c.get('userId')`. `ipRateLimiter<E>(binding)` — pre-auth variant keyed on `cf-connecting-ip` (`'dev'` locally) for routes that run before identity exists (auth's OAuth routes). |
| `src/rpc-surfaces.ts` | `AuthRpcSurface` / `UsersRpcSurface` (`linkAccount` — promote-or-adopt, returns post-coalesce `avatarHash` + RYW bookmark) / `ImagesRpcSurface` (`ingestAvatar` — 32-hex \| null, never throws) / `RoomDoRpc` — cross-config RPC contracts (the `AUTH`/`USERS`/`IMAGES` services + cross-script `rooms` DO are untyped across wrangler configs). The contract sits on both ends: producers declare `implements <Surface>` (drift fails natively at the class — `room.ts`, `auth/rpc.ts`, `users/rpc.ts`, `images/rpc.ts`); consumers retype the binding via `RefineBindings<Env, {…}>` in their env, so call sites read `c.env.X.method(...)` checked against the surface, no blind cast. The cross-script `rooms` DO is retyped the same way — `RoomDoRpc` extends `Rpc.DurableObjectBranded` (the brand is a string-literal marker shared across `@cloudflare/workers-types` and the generated runtime types), so the consumer types its binding `DurableObjectNamespace<RoomDoRpc>` and calls `c.env.rooms.getByName(id).setTitle(...)` with no cast — ZERO cast sites remain. `RoomDoRpc.setPermission`/`setTitle` take `(caller, …)` — the DO reads its own `ctx.id.name` (`asRoomId(this.name)`), so no room-id argument and no identity proof — return the post-mutation `MetaEvent` snapshot for the users worker's direct rev-guarded D1 write + bookmark, and throw `forbidden`/`invalid-title` as the wire error contract. `RefineBindings<Base, Overrides>` (omit-and-intersect; pass the global `Env`, NOT `Cloudflare.Env` — its merged-namespace `keyof` is `never` under tsgo) does the per-consumer retype. |
| `src/zod/anon-token.ts` | `AnonToken` — post-HMAC `avlo_anon` cookie payload `{ userId, iat, nonce }`. `safeParse`d by `cookies.ts` (mint + verify), not a `zValidator`. |
| `src/zod/avatar-hash.ts` | `avatarHashParam` — `{ hash: regex(/^[0-9a-f]{32}$/) }` for `GET /avatars/:hash`. Canonical lowercase like `asset-key.ts`. |
| `src/zod/asset-key.ts` | `assetKeyParam` — `{ key: regex(/^[0-9a-f]{64}$/) }`. Canonical lowercase hex, no uppercase. |
| `src/zod/content-length.ts` | `contentLengthBound(max)` + `MAX_UPLOAD_BYTES = 10MB`. Hono `header` validator that rejects oversize requests BEFORE the body is awaited (H2). |
| `src/zod/room-event.ts` | `VisitEvent` / `MetaEvent` — branded-on-parse queue event schemas (§6). `safeParse`d by the `users` queue consumer so a poison body acks to DLQ. |
| `src/zod/url-param.ts` | `unfurlQuery` — `{ url: normalizeUrl + isPrivateHost refine }`. SSRF guard runs inside Zod (H9). The null-refine carries `abort: true` — zod v4 keeps running later checks after a failure, and without it the SSRF refine executes `new URL(null)` and 500s every unparseable URL. |

See `TESTING.md`. |

## Invariants

- **Barrel-only exports.** No subpath exports in `package.json`. Every consumer imports from `@avlo/worker-shared`. Keeps the public surface flat and the package.json minimal.
- **`zod/` is the home for every schema.** All `zod/v4` schemas live in `src/zod/` — request validators (`assetKeyParam`, `contentLengthBound`, `unfurlQuery`) AND parse/`safeParse` data schemas (`AnonToken` for the signed cookie, `VisitEvent`/`MetaEvent` for the queue). The modules that *use* them (`cookies.ts`, the queue consumer) import from `./zod/*`. Keeps every schema greppable in one place. The `app-type.ts` mocks are the one exception — their inline schemas stay inline (ambient-free isolation; a mock must not import worker-shared).
- **`responses.ts` is intentionally absent.** Earlier drafts had `jsonErr`/`notFound` helpers; they were never used. Most workers want raw `new Response(...)` for full header control. Reintroduce only if there's a real call site.
