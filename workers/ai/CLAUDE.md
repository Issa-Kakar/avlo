# workers/ai — the AI host (`avlo-ai`, `ai.avlo.io`, dev :8794)

Per-(user, room) AI agent on the Cloudflare **Agents SDK** (`agents` + `@cloudflare/ai-chat`, AI SDK v6, zod v4 — all pinned to the `ai ^6` peer line; v7 exists, do NOT bump past the ai-chat peer range). WSS + chat HTTP on `/agents/*`; everything else 404s. WSS-primary ⇒ **App-Type exempt** (like sync) — add `src/app-type.ts` + drift guard + api-client entry only when a client-facing `hc` HTTP route lands.

**The worker is the brain; the client is the hands.** Canvas tools (`canvas`, `canvas_read`) have NO `execute` — they surface in the browser (`useAgentChat` `onToolCall`, `web/src/core/ai/apply-actions.ts`) where model output is re-validated and applied to the Y.Doc. This worker never touches a Y.Doc; the LLM never sees the request/env/headers (tools get validated args + narrow ports only). Wire schemas are shared: `@avlo/shared` `src/ai/{actions,context,limits,protocol}.ts` — full protocol in `docs/ai/protocol.md`.

## Invariants

- **The edge gate is the auth boundary.** Nothing unauthenticated or name-mismatched reaches a DO. The DO-side onConnect check is defense-in-depth only.
- **Model output is untrusted everywhere** — zod at the tool-input layer (AI SDK), zod AGAIN client-side before the Y.Doc. Unknown short-ids drop actions, never guess.
- **Prompt-cache discipline**: system prompt + tool schemas byte-stable; history append-only (context rides ON user messages, inlined deterministically); no reordering; compaction (future) only at deliberate boundaries.
- **Quota is charged pessimistically**: reserve before the model, settle replaces with actuals, failures keep the estimate. `RL_AI` (namespace **1005**) is edge damping, not accounting. **Quota NUMBERS (`@avlo/shared/ai/limits.ts`) are mutable scaffold values** — deliberately dev-loose at this first integration step (200 msgs/day is NOT a ship value); refine them freely as concrete usage lands. Only the bucket shapes + reserve/settle protocol are contract.
- **Storage model**: a user's AI history lives in THIS worker's DOs, keyed by the user — never in the room DO (`AvloDO`/sync is untouched by AI). Conversations are per-(user, room) instances because a thread is inseparable from one board's context (short-ids, chat-origin coords, canvas snapshots); per-USER state (budgets today, a cross-room conversation index later) belongs in the per-user `AiQuota` DO, which is the natural seam to grow into a user AI-profile DO. Two users in the same room have fully separate conversations.
- Client counterparts: `web/src/core/ai/` (short-ids/serializer/executor), `web/src/components/ai/` (panel + hook), `web/src/stores/ai-panel-store.ts`. Wire constants come ONLY from `@avlo/shared`.

## Dev

Boots inside the single-Miniflare orchestrator (port 8794 + offset; `unsafeDirectSockets` carries the WS upgrade — verified). The orchestrator's esbuild rewrites bare node-builtin imports (`path` etc., pulled by the agents graph) to external `node:*`. The AI binding is `remote: true` — local dev hits the real network (10k neurons/day free), needs `CLOUDFLARE_ACCOUNT_ID`/`CLOUDFLARE_API_TOKEN` in the environment for `wrangler dev`; without creds/key the chat model errors at call time (the scaffold still boots). Gate probes: see `docs/ai/protocol.md` §verification.
